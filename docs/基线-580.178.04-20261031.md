## ⚠ 本基线修正了一个测量陷阱

**短帧数会测到 GPU 爬频阶段，结果偏高近一倍。**

```
0 %,  139 MHz   ← 刚启动
84 %, 493 MHz   ← 升频中（约 2~3 秒）
63 %, 1911 MHz  ← 满频
```

| 测法 | 原生 GL n=400 -s |
|---|---|
| `-f 30 ~ 40`（短） | **48 µs**（假） |
| `-f 400`（长） | **22 µs**（真） |

**⇒ 以后所有 GL/Vulkan 测量必须跑 ≥400 帧，并跑两遍确认一致。**
lavapipe 是纯 CPU，不受此影响。
